# **4\. StockPilot — Frontend Specification & UI Style Guide Document**

* # **4.1 Design Direction, TweakCN `caffeine` Theme & CLI-Only Styling Mandate**

* **Canonical Theme Source:** StockPilot uses the exact [**TweakCN Caffeine Theme**](https://tweakcn.com/editor/theme?theme=caffeine) ("Rich coffee browns for focus" in Light and Dark modes using modern OKLCH/CSS variable tokens).  
* **Strict CLI-Only Installation & Zero Custom CSS Policy:**  
  * **Initialize Shadcn UI (Latest):** `npx shadcn@latest init -d`  
  * **Apply Caffeine Theme via CLI Only:** `npx shadcn@latest add https://tweakcn.com/r/themes/caffeine.json`  
  * **Add UI Primitives via CLI Only:** `npx shadcn@latest add button card table badge dialog sheet dropdown-menu select input textarea tabs tooltip alert sonner separator skeleton scroll-area progress avatar breadcrumb`  
  * **No Manual Config or CSS Edits:** Developers and AI agents MUST NEVER manually edit `src/app/globals.css`, `components.json`, `postcss.config.mjs`, `next.config.ts`, or `tsconfig.json`.  
  * **No Hardcoded Palette Classes:** Never write raw Tailwind color classes like `bg-slate-900`, `bg-blue-600`, or `border-gray-200`, and never write custom `.css` files or inline `style={{}}` overrides. Every component MUST use the semantic Shadcn tokens injected by the `caffeine` theme (`bg-background`, `bg-card`, `bg-primary`, `bg-secondary`, `bg-muted`, `bg-accent`, `bg-destructive`, `border-border`, `text-foreground`, `text-muted-foreground`).

# **4.3 Typography Scale & Numeric Formatting Rules**

* **Theme Font Variables (Configured Automatically by `caffeine` Theme):**  
  * **Primary UI Font (`font-sans` \-\> `var(--font-sans)`):** Used for headings, navigation, form labels, and table descriptions.  
    * **Page Title (`H1`):** `text-2xl font-semibold tracking-tight text-foreground`  
    * **Section / Card Header (`H2`):** `text-base font-semibold text-card-foreground`  
    * **Dense Table Cell & Body:** `text-xs sm:text-sm font-normal text-foreground`  
    * **Table Column Header & Badges:** `text-xs font-medium uppercase tracking-wider text-muted-foreground`  
  * **Monospace / Financial & SKU Font (`font-mono tabular-nums` \-\> `var(--font-mono)`):**  
    * Mandatory (`font-mono tabular-nums`) on all: SKU strings (`GPU-RTX4080S-16G`), PO/SO reference numbers (`PO-2026-0042`), Monetary figures (`USD $1,199.00`), Stock Quantities (`142`), Signed Ledger Deltas (`+25`, `-4`), and ISO Timestamps.  
  * Every monetary figure rendered in the UI must use `formatMoney(amountCents, currencyCode)` which outputs the explicit ISO currency code \+ symbol (e.g., `USD $48,250.00` or `PKR Rs 1,450,000.00`).

# **4.4 Responsive Grid & Warehouse Device Breakpoints**

* **Desktop Operational View (`xl:` and `2xl:`):**  
  * Fixed left `<Sidebar />` (`bg-sidebar border-r border-sidebar-border`), sticky top header (`h-14 bg-background/95 backdrop-blur border-b border-border`), fluid main container (`p-6 space-y-6`).  
  * Data tables display all columns simultaneously with sticky right action columns.  
* **Warehouse Tablet Receiving View (`md:` to `lg:`):**  
  * Collapsible icon-rail sidebar.  
  * Touch-friendly Shadcn `<Button size="lg" />` stepper controls on the **PO Stock Receipt** and **Cycle Count Adjustment** screens for gloved or handheld barcode scanner operation.  
* **Mobile Manager View (`< md`):**  
  * Shadcn `<Sheet />` slide-over navigation drawer, `grid-cols-1 sm:grid-cols-2` KPI summary grid, horizontally scrollable `<ScrollArea />` tables with sticky `SKU` left column, and sticky bottom approval bar (`bg-card border-t border-border p-4`) for quick Manager PO sign-off.

# **4.5 Detailed Screen & Component Specifications**

## **4.5.1 Global Application Shell & Network/Polling Status Bar**

* **Top Header Bar Components:**  
  * **Location Context Selector:** Shadcn `<Select />` filtering all views by `All Locations` or a specific physical store/warehouse (`Main Showroom`, `Central Warehouse`), persisted in URL search params (`?locationId=...`).  
  * **Theme Mode Toggle (`<ThemeToggle />`):** Switches between `caffeine` Light Mode and `caffeine` Dark Mode via `next-themes@latest` without touching any CSS files.  
  * **Live Sync & Network Health Pill (`<PollingStatusBadge />` using Shadcn `<Badge />`):**  
    * *Connected / Synced:* `<Badge variant="secondary">` \+ pulsing indicator \+ `Live • Updated 3s ago`.  
    * *Polling in Flight:* `<Badge variant="outline">` \+ `Syncing ledger...`.  
    * *Network Fluctuation / Degraded:* `<Badge variant="secondary">` \+ `Weak Connection • Retrying in 4s (Last synced 22s ago)` \+ manual `<Button variant="ghost" size="sm">Sync Now</Button>`.  
    * *Offline:* `<Badge variant="destructive">` \+ `Offline Mode — Stock mutations paused until connection restores`.  
    * Top banner (`bg-secondary text-secondary-foreground border-b border-border px-4 py-1.5`) allowing instant 1-click switching between demo personas (`Owner`, `Store Manager`, `Procurement Officer`, `Warehouse Clerk A`, `Warehouse Clerk B`, `Sales Associate`, `Auditor`) and a **"Simulate Concurrent PO Receipt"** button to test race conditions live.

## **4.5.2 Screen 1: Inventory Overview Dashboard (`/overview`)**

* **Top Filter Toolbar:**  
  * Shadcn `<Tabs />` Date Range Control (`Today`, `7D`, `30D`, `90D`, `Custom`) \+ Category `<Select />` \+ Location `<Select />`.  
* **4 KPI Metric Cards (`grid-cols-1 sm:grid-cols-2 xl:grid-cols-4 gap-4` using Shadcn `<Card />`):**  
  * **Card 1 — Total Active SKUs:** Primary `font-mono tabular-nums text-2xl font-bold`, active vs. discontinued sub-label in `text-muted-foreground`.  
  * **Card 2 — Total Stock Valuation:** Exact valuation in explicit currency (`USD $284,910.50`), calculated across `on_hand_qty * unit_cost_cents`, with delta `<Badge variant="secondary">`.  
  * **Card 3 — Low & Out-of-Stock Items:** Uses `<Badge variant="destructive">` when `> 0`; clicking filters the Product Catalog directly to `status=LOW_STOCK,OUT_OF_STOCK`.  
  * **Card 4 — Pending Purchase Orders:** Count of POs awaiting approval or warehouse receipt \+ total committed PO value.  
* **Charts Row (`grid-cols-1 lg:grid-cols-3 gap-6`):**  
  * **Chart A (`lg:col-span-2`) — Stock Movement Velocity (Recharts Composed Chart inside Shadcn `<Card />`):**  
    * Uses `var(--chart-1)` for Inbound (`PO_RECEIPT`, positive adjustments), `var(--chart-2)` for Outbound (`SALE_FULFILLMENT`), and `var(--destructive)` for Shrinkage/Negative Adjustments.  
    * **Custom Tooltip Specification:** Rendered inside a `bg-popover text-popover-foreground border border-border rounded-md shadow-md p-3` container displaying: Exact Date Header, Inbound Units (`+120 units / USD +$18,400.00`), Outbound Sold (`-85 units / USD $29,750.00`), Adjustments (`-2 units / USD -$340.00`), Net Balance Delta (`+33 units`), and Top Moving SKU of that day.  
  * **Chart B (`lg:col-span-1`) — Valuation by Hardware Category (Recharts Donut Chart):**  
    * Uses `var(--chart-1)` through `var(--chart-5)`.  
    * **Custom Tooltip Specification:** Category Name, Exact Valuation (`USD $94,200.00`), Share of Total Inventory (`33.1%`), Total Units (`412`), and Low-Stock SKUs in Category (`3`).  
* **Recent Stock Movements Table:**  
  * Compact 10-row live ledger feed built with Shadcn `<Table />`: `Timestamp`, `Movement ID`, `SKU & Product`, `Location`, `Type Badge`, `Delta (Signed Monospace)`, `Balance After`, `Reference (Clickable PO/SO/Adj link)`, and `Actor`.

## **4.5.3 Screen 2: Dense Product Catalog & Bulk CSV Import (`/catalog`)**

* **Dense Data Table (`<ProductCatalogTable />` powered by `@tanstack/react-table@latest` \+ Shadcn `<Table />`):**  
  * Compact row density (`h-10`), sticky header (`bg-muted/50`), virtualized scrolling for 5,000+ SKUs.  
  * **Exact Column Specification:**  
    1. `Image`: `Avatar` (`h-8 w-8 rounded-md`) hardware thumbnail with fallback category icon.  
    2. `SKU` (`font-mono tabular-nums font-medium`): Copy-on-click SKU code \+ barcode icon `<Tooltip />`.  
    3. `Product & Variant Name`: Primary title (`text-foreground`) \+ subtle attribute `<Badge variant="outline">` pills (`16GB GDDR6X`, `PCIe 4.0`).  
    4. `Supplier`: Supplier name \+ lead time `<Badge variant="secondary">` (`4d`).  
    5. `Unit Cost` (`text-right font-mono tabular-nums`): Explicit currency (`USD $820.00`). Hidden for roles without cost visibility.  
    6. `Selling Price` (`text-right font-mono tabular-nums`): Explicit currency (`USD $1,099.00`) \+ gross margin `<Badge variant="outline">` (`25.4%`).  
    7. `On Hand / Reserved / Available` (`text-right font-mono tabular-nums`): Displays `Available` in bold (`14`), with `<Tooltip />` breakdown `(18 On Hand - 4 Reserved)`.  
    8. `Reorder Status` (`text-center`): Shadcn `<Badge variant="default | secondary | destructive">` (`IN STOCK`, `LOW STOCK (<= 5)`, `OUT OF STOCK (0)`) \+ auto-drafted PO link if triggered.  
    9. `Actions` (`text-right`): Shadcn `<DropdownMenu />` with quick links to *View Ledger*, *Create PO*, *Adjust Stock*, or *Edit Metadata* (role-gated).  
* **Bulk CSV Import Screen (`/catalog/import`):**  
  * **Step 1 (Dropzone Card):** Shadcn `<Card />` file upload zone \+ `<Button variant="outline">Download Strict CSV Template</Button>`.  
  * **Step 2 (Validation Preview Table):**  
    * Displays Shadcn `<Alert />` banner: `500 Rows Parsed: 486 Valid (Ready to Import) • 14 Invalid (Will Be Safely Rejected)`.  
    * Shadcn `<Tabs />`: `All Rows (500)`, `Invalid Only (14)`, `Valid Only (486)`.  
    * Invalid rows use `bg-destructive/10 text-destructive` with `<Tooltip />` field-level error explanations (e.g., `unit_cost: "-45.00" -> Error: Unit cost must be a non-negative amount`, `sku: "=CMD()" -> Error: Formula injection character blocked`).  
  * **Step 3 (Commit Actions):**  
    * `<Button variant="secondary">Download Rejected Rows CSV (14 rows)</Button>`  
    * `<Button variant="default">Import 486 Valid Rows & Safely Reject 14 Invalid Rows</Button>` (executes idempotent batch commit).

## **4.5.4 Screen 3: Purchase Order Lifecycle & Concurrent Receiving (`/purchase-orders/[poId]/receive`)**

* **PO Header & Status Stepper:**  
  * Visual progress stepper using Shadcn `<Badge />` and `<Separator />`: `1. Draft` \-\> `2. Submitted` \-\> `3. Approved & Ordered` \-\> `4. Partially Received` \-\> `5. Fully Received`.  
* **Interactive Receiving Table:**  
  * Lists each PO line item with: `SKU`, `Product Name`, `Ordered Qty`, `Previously Received Qty`, `Remaining Receivable Qty` (with Shadcn `<Progress />` bar), and a controlled `Receive Now Qty` `<Input type="number" />` (`min=0`, `max=remaining_qty`).  
  * Includes a `<Button variant="secondary">Fill All Remaining</Button>` convenience button and per-line batch/condition `<Input />` notes.  
* **Idempotency & Concurrency Conflict Resolution UX:**  
  * When the clerk clicks `<Button variant="default">Confirm Stock Receipt</Button>`, the button disables and shows the active idempotency lock (`Receiving Stock...`).  
  * If another clerk simultaneously received items on the same PO, the UI catches the backend `409 Conflict` response, renders a Shadcn `<Alert variant="destructive">` banner (`Clerk Sarah just received 6 units of RTX-4080S 2 seconds ago. Remaining receivable quantity has been updated to 4 units.`), and updates the remaining bounds automatically without losing the user's unsaved notes.

## **4.5.5 Screen 4: Controlled Stock Adjustment & Anomaly Review Queue (`/adjustments`)**

* **New Adjustment Form (Shadcn `<Card />` \+ `<Select />` \+ `<Input />` \+ `<Textarea />`):**  
  * Requires selecting `Location`, `Product Variant`, `Adjustment Direction`, `Quantity`, `Reason Code` dropdown, and `Detailed Explanation` `<Textarea />` (live character counter enforcing `>= 15 chars`).  
  * **Live Before/After Preview Card:** Uses `bg-muted p-4 rounded-md font-mono tabular-nums` showing `Current On-Hand: 25` \-\> `Adjustment: -8` \-\> `New On-Hand: 17` and `Financial Impact: USD -$2,400.00`.  
  * **Pre-Submission Anomaly Notice:** If the adjustment crosses the suspicious threshold (`>= $500` or `> 10%` of stock), a Shadcn `<Alert />` informs the user that the adjustment will be flagged for mandatory Manager Review in the Audit Queue.
